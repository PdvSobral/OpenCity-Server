## Overview
This repository contains the api server for OpenCity (https://github.com/PdvSobral/OpenCity).

## Installation
This project was tested on Python 3.13.5, but most python 3.x environments should work.

1. Clone Repository

```bash
git clone <repository-url>
cd <repository-folder>
```
2. Setup Python environment
Although not needed, we highly recommend creating a python virtual environment. 

3. Install required packages

```bash
pip install -r requirements.txt
```
4. Databse Setup

If `db.sqlite3` exists, remove it.
Then `copy env.txt` to `.env`.
Update the configuration values according to your needs.
The project is currently setup to work only with PostgreSQL.
Some migrations inject code directly into the database, without going through the driver selection mechanism.
Having said that, ensure that:
- PostgreSQL is installed and accessible;
- The target database exists; 
- The configured user has sufficient privileges.
To test if the connection is successful, the following command can be used:
```bash
python manage.py dbshell  --database app_db
```
If a shell is provided and no error arises, the connection was successful. Use `\q` to exit back to the terminal.

5. Apply migrations

**Note: If the database is not empty, please refer to `Resetting the Database`.**
```bash
python manage.py migrate
python manage.py migrate --database=app_db
```
6. Populate Test Data (Optional)

If you require test data, the following command can be used.
```bash
python manage.py add_debug_data --database=app_db
```

## Running the Application
Start the development server:
```bash
python manage.py runserver
```
By default, the application will be available at:
```text
http://127.0.0.1:8000/
```

## Resetting the Database

### Warnings
**All existing data will be permanently removed.**

Delete `db.sqlite3` if it exists.
Ensure the PostgreSQL database exists and that the configured user has sufficient permissions.
Run:
```bash
python manage.py reset_db --database=app_db
```
Confirm the operation when prompted:
```text
Type 'YES' to continue: YES
```
After resetting the database, recreate the schema:
```bash
python manage.py migrate
python manage.py migrate --database=app_db
```
